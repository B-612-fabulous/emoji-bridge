# 下一个产品方向总结（含法律风险边界）

> 基于「表情搬运工」沉淀的能力，对「还能做什么类型的软件」的结论与合规边界。
> 日期：2026-10-24

---

## 一、你手里的三张王牌（可平移的资产）

1. **WebView 内嵌登录 + JS 桥 + 遮罩注入**：市面上多数同类 App 卡在这一层，你已完整跑通。
2. **反爬签名 + 风控边界判断**：知道「哪些能做、哪些是逆风控死路」，这是稀缺经验。
3. **动态 WebP → GIF 媒体管线**：纯技术资产，可无限复用。

---

## 二、市场结论：红海 vs 空白

### 已经卷死、别碰（搜索坐实）

- **表情包素材库 + DIY + 分享**（最火表情包 / 斗图 / 闪萌）：纯拼素材量与运营，个人开发者是炮灰。
- **小红书 / 抖音无水印下载器**（XHS-Downloader / 红下载 / PicSeed）：全是「复制链接→解析→下载」同套路。
- **B 站收藏夹导出 / 备份**（BilibiliDown / BDL / Mybili）：开源桌面工具已做穿。

### 关键差异点（护城河）

红海产品都在**绕开登录、绕开反爬**（低门槛，谁都能抄）；
而你的产品走的是 **「账号登录 → 直连收藏列表 → 全量搬出」**（高门槛，别人做不动）。
**空白不在于「做什么功能」，而在于「用哪种门槛」。**

### 三个真实空白方向（都长在护城河上）

| 方向 | 说明 | 复用度 |
|---|---|---|
| A. 跨平台收藏汇总器 | 一个 App 把抖音/小红书/B 站等收藏全量搬到本地统一管理 | 最高 |
| B. 平台数据搬家 / 备份 | 收藏失效前自动备份、换机迁移 | 高 |
| C. 收藏内容再创作 / 检索 | 本地搜索、打标、去重、成册导出 | 中 |

**建议先做 A（跨平台收藏汇总器）**：市场真缺 + 复用率最高 + 需求真实。
每接一个新平台只是「换一套页面锚点 + 换一个接口」的活。

## 三、法律风险边界（红线必须守住）

### 绝不能碰的高风险红线

1. **破解/绕过技术保护措施**：不为获取内容去破解签名、绕过 DRM 或付费墙。
   （「表情搬运工」用的是用户自己账号走官方登录、直连公开接口，不是破解——这条要守住。）
2. **抓取他人未公开内容 / 批量爬取牟利**：只做「用户本人账号里、自己收藏的内容」。
3. **盗版 / 付费内容搬运**：不碰付费课程、会员专属、影视原片。

### 安全区（当前产品已踩在区内）

- 用户**本人登录自己的账号**、导出**自己收藏的公开内容**到本地，不转卖不公开传播 → 个人合理使用，风险低。
- **纯本机、不碰凭证**（不存不上传账号密码/Cookie）→ 规避「非法获取个人信息」这条大线。

### 主动设防的合规动作

| 动作 | 目的 |
|---|---|
| 隐私政策明确「仅处理用户本人授权内容，不采集密码、不上传 Cookie」 | 规避个人信息保护风险 |
| 不内置「破解/去水印绕过会员」功能 | 规避著作权技术措施风险 |
| 明确「与平台无关联、仅作个人数据管理」 | 规避商标/不正当竞争纠纷 |
| 跨平台汇总只碰「公开 + 用户本人」内容，不碰私密/付费 | 守住数据边界 |
